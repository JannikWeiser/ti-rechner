# TI-Rechner Klettern

Mobile Web-App für Officials: berechnet nach einem **Technischen Zwischenfall (TI)**, wann der Athlet wieder einsteigt.

- **Lead:** Erholungszeit (1 min pro gewertetem Griff, max. 20 min), frühester Neustart, Countdown
- **Boulder:** Rotation-Slot nach Judge Guide §5.2, Lücke an B1, Gutschrift (§8.5), sekundäre Isolation, Live-Countdown

📱 Offline nutzbar: Seite öffnen → „Zum Home-Bildschirm“.

👉 **Live:** https://jannikweiser.github.io/ti-rechner/
